# D60 AutoDL 完整训练与启动手册

## 1. 实验定义

D60 是此前 D10 的完整 60 轮版本，并作为 E60、F60、G60 的参照单元：

```text
环境：whu_mars
CUDNN_BENCHMARK：False
SEED：1234
MAX_EPOCHS：60
STOP_AFTER_EPOCH：0
逻辑训练 batch：64
实际图片 batch：192
测试 batch：1024
```

实验从 `ViT-B-16.pt` 重新开始，不加载 `transformer_10.pth` 续训。AutoDL 使用独立代码目录和独立输出目录，不覆盖服务器上已有的 WHU-Baseline 快照。

## 2. AutoDL 路径

```text
代码：/root/autodl-tmp/XK/WHU-Baseline-env-cudnn-e60
Python：/root/autodl-tmp/envs/whu_mars/bin/python3
数据集：/root/autodl-tmp/WHU-MARS
CLIP权重：/root/autodl-tmp/ViT-B-16.pt
输出：/root/autodl-tmp/XK/WHU-Baseline_runs/diagnostic_e60/D60_whu_benchmark_false
```

## 3. GPU 启用后的预检

当前启动脚本按 A800 80GB 设置，保留 `TEST.IMS_PER_BATCH=1024`。实例启用 A800 后先运行：

```bash
bash /root/autodl-tmp/XK/WHU-Baseline-env-cudnn-e60/server/preflight_D60_autodl_a800.sh
```

只有最后出现以下标记才可开始训练：

```text
D60_AUTODL_A800_PREFLIGHT_OK
```

预检要求 GPU 显存不少于 70GiB。如果实例改租24GB GPU，不要直接运行本启动脚本；应先把验证 batch 改为256。

## 4. 正式启动命令

使用单卡前台任务，不使用 `nohup`、`&` 或 `torchrun`：

```bash
bash /root/autodl-tmp/XK/WHU-Baseline-env-cudnn-e60/server/run_D60_whu_benchmark_false_autodl.sh
```

脚本会拒绝复用非空输出目录，完整训练60轮后检查 `transformer_60.pth`，再从磁盘重载该权重完成独立复评。

## 5. 完成条件

1. `train_stdout.log` 正常完成 epoch 60；
2. 存在非空 `transformer_60.pth`；
3. `eval_epoch60/eval_stdout.log` 完成磁盘重载复评；
4. 日志末尾出现 `D60_TRAIN_AND_DISK_RELOAD_EVAL_OK`；
5. 输出目录包含 `git_commit.txt`、`pip_freeze.txt` 和 `nvidia_smi.txt`。
